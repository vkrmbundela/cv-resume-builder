# Security Policy

## Supported Versions

Security fixes are applied to the latest `main` branch.

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Email: opensource@iithresumebuilder.org
Subject: [SECURITY] IITH Resume Builder vulnerability report

Include:
- A clear description of the issue
- Steps to reproduce
- Potential impact
- Suggested remediation (if known)

We will acknowledge reports within 5 business days and provide status updates.

## Data and Privacy Notes

This project processes resume content that may contain personally identifiable information.
Contributors should avoid logging raw resume content, and should sanitize test fixtures before sharing.
