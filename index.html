Student Resume Builder

Unofficial assistant for compliant resumes
Independent project by Vikramaditya Shah Bundela
How To Use
  1. Start and understand autosave: begin typing in any field in the left editor. Your changes are saved automatically in browser local storage. If you close or refresh the page, your draft should recover on next open.
  2. Complete Basic Info first: fill name, roll number, degree, department, institute, phone, email, LinkedIn, and GitHub. Use a clear date and contact format because validation highlights invalid fields.
  3. Optional custom logo: in Controls, use Custom Logo to upload an image. Use PNG/JPG for best reliability. Use Reset To Default Logo any time to restore the neutral default logo. Upload institutional logos only if you have permission to use them.
  4. Fill section content in order: Education, Experience, Projects, Skills, Achievements, Positions of Responsibility, Key Courses, and Extracurriculars. Use + Add to create entries and Remove to delete entries.
  5. Write strong bullets: use one bullet per line in bullet textareas. Prefer action + scope + outcome + metric (for example: improved throughput by 35%). The diagnostics panel warns about weak or metric-free bullets.
  6. Open advanced controls: click the Settings icon (top-right) to configure: section visibility, section density, role preset, ATS mode, target pages, strict print calibration, variant snapshots, and data management.
  7. Use role presets intelligently: Software/Core/Research/Design presets reorder sections. Choose the preset closest to your application target before exporting.
  8. Manage resume length: check diagnostics for page-budget warnings. If over budget, reduce bullets or change dense sections to Compact/Tight from Settings.
  9. Use Variant Snapshots: save different versions (for example: Internship, Full-time, Research-heavy). Load or delete variants from Settings at any time.
  10. Export correctly: click Download / Print PDF and choose: Export PDF, Print, or Export DOC. For final submissions, review PDF margins and page breaks before sending.
  11. Use LaTeX workflow: click Copy LaTeX to copy generated LaTeX for Overleaf/local use. This is useful when you need further manual formatting edits outside this tool.
  12. Backup and restore across devices: in Settings, use Backup JSON to download your data, and Restore JSON on another browser/device. Use Clear Local Data only when you intentionally want to wipe browser-stored drafts.
  13. Keyboard shortcuts: Ctrl/Cmd + S saves to local cache, Ctrl/Cmd + Shift + S downloads backup JSON, Ctrl/Cmd + P opens print, Esc closes open panels.
  14. Troubleshooting quick checks: if something looks off, refresh once, confirm section toggles in Settings, verify invalid field highlights, and re-export.
