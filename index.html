Student Resume Builder

Unofficial assistant for compliant resumes
Independent project by Vikramaditya Shah Bundela
How To Use
  1. Start writing and rely on autosave: begin in the left editor. Every valid change is saved to browser local storage and restored on next open.
  2. Complete Basic Info before sections: fill name, roll number, degree, department, institute, phone, email, and links. Resolve highlighted invalid fields first.
  3. Set header presentation in Controls: upload/reset image, adjust image width/height, choose shape and fit, set name-block alignment (Left after photo or Center page), and tune font + line spacing.
  4. Choose contact style for links: set Social Link Display (Text hyperlinks, Logos only, or Logos + text), choose Contact Link Spacing, and optionally hide GitHub/Portfolio in the header.
  5. Fill sections in priority order: Education, Experience, Projects, Technical Skills, Achievements, POR, Key Courses, and Extracurriculars. Use + Add, Up/Down, and Remove to curate each section.
  6. Write stronger bullets using diagnostics: prefer action + scope + measurable result. Keep bullets concise and use diagnostics/content-coach hints plus the section-level quality hints shown above Experience/Projects/Achievements.
  7. Use quick actions for safety: from Controls, run Backup JSON, Restore JSON, Save Restore Point, and Export Readiness Report. Use Normalize All Dates to standardize date ranges in one click before export.
  8. Open Settings and acknowledge legal notice: this confirms you understand responsibility for factual claims and authorized logo/trademark usage.
  9. Use Settings > Advanced Controls intentionally: use the Settings search bar to jump to controls quickly, pin frequently used controls (click the star) to keep them at the top, Template Pack applies profile-oriented defaults, Role Preset changes section emphasis/order, Export Preset tunes final output styling, Density Preset sets compactness, Print Profile switches ATS-safe/visual/publication mode, Target Pages changes page-budget diagnostics, and toggles control ATS mode, strict print calibration, strict links, and content coach. Use the built-in before/after mini preview to see density + ATS impact instantly.
  10. Use Settings > Structure controls: in Add / Remove Sections choose what appears, in Section Density set normal/compact/tight per section, and in Custom Section Order reorder sections for your target role.
  11. Use snapshots before experiments: in Variant Snapshots save named versions (for example SDE, Core, Research), and use Version Compare to preview impact before switching.
  12. Use Settings > Data Management carefully: use backup/restore for transfer, save and load restore points for safe rollback, run Normalize All Dates, review the pre-export checklist, and use Clear Local Data only when you truly want a full local reset (a short one-time restore option appears after refresh).
  13. Export with final checks: click Download / Print PDF and choose Export PDF, Print, or Export DOC. Verify spacing, margins, section order, and link validity before submission.
  14. Use LaTeX and shortcuts when needed: click Copy LaTeX for Overleaf/local edits. Shortcuts: Ctrl/Cmd + S save, Ctrl/Cmd + Shift + S backup, Ctrl/Cmd + Z undo, Ctrl/Cmd + Y (or Ctrl/Cmd + Shift + Z) redo, Ctrl/Cmd + P print, Ctrl/Cmd + Shift + P export PDF, Esc closes open panels.
  15. Troubleshooting flow: refresh once, fix highlighted fields, verify Settings toggles/order/density, run Export Readiness Report, then export again.
